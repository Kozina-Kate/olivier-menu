# Проверка качества MVP 2

Чек-лист дополняет автоматические тесты задачи #15. Перед pull request выполните
`npm run check` на версии Node.js из `.nvmrc` и с установленными Python-
зависимостями из `backend/requirements.txt`.

## Основной путь

1. Открыть `/` и клавишей `Tab` выбрать сценарий «Приготовить из продуктов дома».
2. На `/pantry` убедиться, что кнопка поиска рецептов заблокирована без выбора.
3. Выбрать продукты из разных разделов, отфильтровать каталог и проверить, что
   выбор не потерялся.
4. Запустить подбор: фокус должен перейти на заголовок результатов, а полные
   совпадения должны находиться выше частичных независимо от порядка ответа API.
5. Открыть рецепт и вернуться по ссылке «К подбору рецептов»: выбор и результаты
   должны восстановиться в пределах вкладки.
6. Отключить backend и повторить загрузку каталога и подбор: оба состояния должны
   показать понятную ошибку и кнопку «Повторить» без потери выбранных продуктов.

## Регрессия конструктора меню

1. На `/menu` добавить и удалить блюдо, изменить число гостей.
2. Проверить объединение одинаковых продуктов и пересчёт количества.
3. Отметить строку списка покупок, скопировать список и скачать `.txt`.
4. Открыть `/recipes/<slug>` напрямую и вернуться в каталог.

## Адаптивность и доступность

- проверить ширины 320, 375, 768 и 1280 px: горизонтальной прокрутки быть не
  должно, карточки и группы продуктов переходят в одну колонку;
- пройти интерактивные элементы клавишей `Tab`: видимый фокус должен быть у
  ссылок, кнопок, поиска и переключателей продуктов;
- переключить продукт клавишами `Enter` и `Space`, проверить `aria-pressed`;
- проверить подписи поиска, счётчик выбранных продуктов, сообщения `status` и
  ошибки `alert` экранным диктором либо в accessibility tree браузера;
- включить `prefers-reduced-motion`: плавная прокрутка и переходы отключаются.

## Покрытие автоматическими тестами

- Django/DRF: публичный каталог, черновики, валидация ID, обязательные продукты,
  ранжирование, стабильная сортировка и отсутствие N+1;
- React Testing Library: маршруты, выбор и снятие продуктов, disabled CTA,
  полный/частичный/пустой результат, ошибки с повтором, клавиатура и полный путь
  `/ → /pantry → результаты → рецепт → назад`;
- Vitest: расчёт порций, объединение списка покупок, копирование и скачивание,
  преобразование ответа API в модель интерфейса.
